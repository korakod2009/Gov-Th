# Roblox RP Prime Minister Election — secure starter

เว็บไซต์ตัวอย่างภาษาไทยสำหรับกิจกรรมเลือกตั้งนายกรัฐมนตรีใน Roblox RP มีหน้าผู้สมัคร การค้นหา สถานะเลือกตั้ง และผลคะแนนจากฐานข้อมูล SQLite

## สำคัญด้านความปลอดภัย
- โครงการนี้ **ปิดการลงคะแนนไว้โดยค่าเริ่มต้น** (`ELECTION_OPEN=false`).
- เส้นทาง `/auth/roblox` ตั้งใจตอบกลับ 503 จนกว่าจะติดตั้ง Roblox OAuth/OIDC อย่างถูกต้อง ผู้ใช้ห้ามส่ง Roblox ID เองเพื่ออ้างตัวตน
- ระบบบันทึกคะแนนมี `UNIQUE(roblox_user_id)` ในฐานข้อมูล ดังนั้นผู้ใช้ Roblox ID เดียวกันจะลงคะแนนได้ไม่เกินหนึ่งครั้ง แม้ส่งคำขอซ้ำพร้อมกัน
- ต้องตรวจสอบสิทธิฝั่งเซิร์ฟเวอร์ ไม่ใช่พึ่งปุ่มหรือ JavaScript ในเบราว์เซอร์
- มี session cookie แบบ HttpOnly/SameSite, rate limit, Helmet, audit log และการแยกสิทธิ admin ตาม ID ที่ตั้งค่าไว้
- ข้อมูลผู้สมัครเป็นข้อมูลสมมติสำหรับเดโม

## เริ่มต้น
1. ติดตั้ง Node.js 20 ขึ้นไป
2. แตกไฟล์ ZIP แล้วเปิดเทอร์มินัลในโฟลเดอร์นี้
3. รัน `npm install`
4. คัดลอก `.env.example` เป็น `.env` และตั้ง `SESSION_SECRET` เป็นค่าสุ่มยาวอย่างน้อย 32 ตัวอักษร
5. รัน `npm start` แล้วเปิด `http://localhost:3000`

## ก่อนใช้งานเลือกตั้งจริง ต้องทำเพิ่ม
1. ตั้งค่า Roblox OAuth/OIDC ตามเอกสารทางการล่าสุดและตรวจสอบ issuer, audience/client ID, state, nonce, redirect URI และ token ฝั่งเซิร์ฟเวอร์ให้ครบ
2. หลังยืนยันตัวตนสำเร็จเท่านั้น ให้สร้าง session จาก Roblox User ID ที่ยืนยันแล้ว; อย่ารับ ID จาก request body หรือ query string
3. เพิ่ม CSRF protection สำหรับทุก endpoint ที่เปลี่ยนข้อมูล และกำหนด Content Security Policy ที่เข้มงวด
4. ใช้ HTTPS, secret manager, สำรองฐานข้อมูล และจำกัดสิทธิการเข้าถึงเครื่องเซิร์ฟเวอร์
5. ตั้ง `ELECTION_OPEN=true` เฉพาะหลังทดสอบระบบยืนยันตัวตน การนับคะแนน และการกู้คืนข้อมูลแล้ว
6. กำหนดนโยบายความเป็นส่วนตัวและการเก็บ log โดยไม่เก็บข้อมูลส่วนบุคคลเกินจำเป็น

นี่เป็น starter project ไม่ใช่ระบบที่พร้อมใช้เลือกตั้งจริงทันที เพราะการยืนยันตัวตน Roblox ยังไม่ได้ตั้งค่าและการลงคะแนนถูกปิดไว้โดยตั้งใจ
